### Project Overview

This project applies stochastic process models to forecast and analyze stock price movements under uncertainty. Historical stock data are collected from Yahoo Finance and used to estimate model parameters for the Monte Carlo simulation.

Models implemented:
- Geometric Brownian Motion (GBM)
- Ornstein-Uhlenbeck (OU)
- Merton Jump-Diffusion

Outputs:
- Historical price analysis
- Correlation analysis
- Monte Carlo simulations
- Terminal price distributions
- Confidence intervals
- Value at Risk (VaR)
- Conditional Value at Risk (CVaR)
- Comparative model analysis
